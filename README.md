# CageCash
Mobile-first MMA modeling and betting intelligence UI.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import this repository into Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.

## Important
The included fight board is demo data so the interface works immediately. Keep API keys out of browser code. Add live odds/fighter data through server-side endpoints or serverless functions.
